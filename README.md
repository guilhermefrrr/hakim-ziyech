# Hakim Ziyech - Fifa World Cup 2022 Analysis

A football data analysis project exploring Hakim Ziyech's passing performance during the 2022 Fifa World Cup. Using Python and pandas, the project cleans and analyzes the data and creates visualizations to investigate Ziyech's playmaking and contribution on the pitch.

## Objectives

- Explore Hakim Ziyech's passing actions during the 2022 Fifa World Cup.
- Clean and organize the data for analysis.
- Calculate descriptive statistics to summarize his performance.
- Use visualizations to make patterns in his passing and playmaking easier to understand.

## Technologies

- **Python:** data analysis and processing.
- **pandas:** data manipulation and cleaning.
- **Jupyter Notebook:** development and documentation of the analysis.
- **Data visualization:** visual exploration of passing performance.

## Project files

- `Code.ipynb`: Jupyter Notebook containing the analysis workflow.
- `Report.pdf`: written report presenting the project and its findings.
- `Presentation.pdf`: presentation summarizing the project.

## How to explore the project

1. Open `Code.ipynb` in Jupyter Notebook, JupyterLab, or Google Colab to review the analysis.
2. Read `Report.pdf` for the written report.
3. Open `Presentation.pdf` for a concise overview of the project.
